# GitHubへの公開方法（TOMO0904限定）

こちらは **まだGitHub未公開のZIP** です。公開前のWindows実機確認が済んだら、GitHubへの公開まで実行できます。

## アカウントの安全確認

- 許可するアカウント：`TOMO0904`
- 許可するGitHubユーザーID：`184657574`
- 公開先：`TOMO0904/RiG-PixelLab`（新規の公開リポジトリ）
- 接続中の別アカウントや既存リポジトリには公開しません。
- 公開前に `TOMO0904/PUBLIC` の入力確認を行います。

## 最短手順

1. ZIPを「すべて展開」して `RiG_PixelLab_2026` を開きます。
2. Git（`git`）とGitHub CLI（`gh`）が未導入なら、Windowsのターミナルで次を実行します。

   ```powershell
   winget install --id Git.Git --exact
   winget install --id GitHub.cli --exact
   ```

   インストール後はターミナルを開き直してください。
3. `PUBLISH_TO_GITHUB_Windows.bat` をダブルクリックします。必要な場合はブラウザでGitHubにログインします。
4. 実際に認証されているログイン名・数値ユーザーIDが一致していることを確認後、`TOMO0904/PUBLIC` と入力します。
5. スクリプトが公開リポジトリを作成し、同梱されたソースコードとサンプルだけを `main` ブランチへ公開します。
6. 完了すると `https://github.com/TOMO0904/RiG-PixelLab` が表示されます。

## 取り扱い上の注意

- スクリプトは **既存の同名リポジトリがあれば停止**します。上書きしません。
- 事前の公開ファイル一覧で承認されたファイルのみをコミットし、プライベートな写真や仮想環境をコミットしません。
- 途中でネットワーク切断などの問題が起きたときは、状態を確認してください。すでにリポジトリが作成されている場合があるので、同じフォルダからむやみに再実行しないでください。
- 公開されるコードのコミットメールアドレスにはGitHubの**非公開メール形式（noreply）**を使用します。
